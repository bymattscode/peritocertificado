## Sobre

O Perito Certificado vende cursos de formação pericial para profissionais de nível técnico e superior, e boa parte deles tem mais idade. Por isso o design prioriza credibilidade e leitura confortável: tipografia grande, contraste alto, navegação simples e animações discretas.

São 12 páginas com a mesma identidade visual, publicadas no WordPress com Elementor.

## Destaques

- Conteúdo programático em abas, com o painel fixo ao rolar
- Depoimentos em duas fileiras que se movem em sentidos opostos no scroll
- Contadores animados quando a seção aparece na tela
- Bordas que ficam douradas no hover
- Layout próprio para celular, sem efeitos de scroll em telas pequenas
- CSS que neutraliza os estilos do tema do WordPress dentro do widget

## Estrutura

Cada página é um único arquivo com HTML, CSS e JavaScript, sem dependências nem etapa de build, pronto para colar num widget HTML do Elementor.

```
index.html
perito-certificado/index.html
grafo-expert/index.html
...
```

Para rodar localmente, basta abrir qualquer `index.html` no navegador.
